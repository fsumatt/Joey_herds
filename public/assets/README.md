# Game assets

`models/joey.glb` — Joey, a stylized golden-and-white corgi created in Blender for this project from owner-supplied photographs. Includes his upright ears, narrow facial blaze, white chest and socks, teal collar, coral tracker and a `Walk` animation. All materials are embedded; no remote model service or texture download is needed. This is an artistic approximation, not a scanned reconstruction.

The game generates sheep and meadow geometry locally in Three.js. Google Fonts provides optional DM Sans and Fraunces typefaces; system and Georgia fallbacks keep the UI usable if that request is blocked.

`art/joey-and-luka.webp` — stylized splash illustration of Joey and Luka, generated from the owner's supplied reference photo using the built-in image-generation tool. The indoor setting, platform and leash were removed. The image retains transparency and is encoded as WebP for fast loading. The original family photograph is not included in the repository.
